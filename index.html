Privacy Policy

Last updated: May 19, 2026

Anchor Point Games built Split Dash: Dual Control as a mobile game.

This Privacy Policy explains how Split Dash: Dual Control handles information when you use the game.

1. Information We Collect

Split Dash: Dual Control does not collect, store, or share personal information from users.

The current version of the game does not include:

  • User accounts
  • Login systems
  • Online leaderboards
  • Advertising SDKs
  • Analytics SDKs
  • In-app purchases
  • Location tracking
  • Camera access
  • Microphone access
  • Contact access

2. Gameplay Data

The game may save basic gameplay progress locally on your device, such as your best score and diamond count.

This data is stored only on your device and is not sent to Anchor Point Games or any third party.

3. Third-Party Services

The current version of Split Dash: Dual Control does not use third-party advertising, analytics, leaderboard, or account services.

If future versions of the game add third-party services, this Privacy Policy will be updated before or when those features are included.

4. Children’s Privacy

Split Dash: Dual Control does not knowingly collect personal information from children.

Since the current version does not collect personal data, no personal information from children is stored or shared.

5. Data Sharing

Split Dash: Dual Control does not sell, share, or transfer personal information to third parties.

6. Data Security

Because the current version does not collect personal data, no personal data is stored on external servers.

Local gameplay data, such as best score, remains on the user’s device.

7. Data Retention and Deletion

Locally saved gameplay data remains on the device unless the user deletes the game or clears the app data from the device settings.

Anchor Point Games does not store user data on external servers for the current version of the game.

8. Changes to This Privacy Policy

This Privacy Policy may be updated if new features are added to the game, such as ads, analytics, online leaderboards, or in-app purchases.

Any changes will be posted on this page with an updated “Last updated” date.
